# UI assets

Typeset is the unmodified [shadcn stylesheet](https://ui.shadcn.com/docs/typeset), pinned to `shadcn-ui/ui@02cad61166c4c20edbc8a3f71bd720eed4c1f49b`. Its MIT license is in `TYPESET-LICENSE.txt`.

Geist and Geist Mono are local variable fonts from `vercel/geist-font@10dc7658f13c38a474cde201bb09a4617267545b`, under `fonts/OFL.txt`. Fonts never load from a third-party server.

`theme.css` supplies the shared light/dark shadcn semantic colors. `styles.css` and the dashboard stylesheet own layout.

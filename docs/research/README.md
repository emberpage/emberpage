# Research evidence

These reports record isolated experiments and the source/tool versions used at the time. They do not establish current service uptime, retention, anonymity, or production adoption. Generated bundles, dependency audit/metafile output, raw logs, browser profiles, and local databases are not tracked.

Before this public source publication, historical JSON reports had local account paths and private IPv4 addresses redacted. Hashes, byte counts, outcomes, and public peer/service references were retained. Browser runners now use Playwright's installed browser or an explicit environment override.

Current development, verification, and release commands are in the root README and `docs/RELEASING.md`; old reports retain their historical commands.

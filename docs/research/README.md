# Research evidence

These are historical experiments, not promises of current uptime, retention, anonymity or production use. Use the [README](../../README.md) and [release guide](../RELEASING.md) for current commands.

Raw reports preserve signed payloads, hashes, sizes and outcomes. Local account paths and private IPv4 addresses were redacted before publication. Generated bundles, raw logs, browser profiles and databases are not tracked.

Old names and commands remain where they identify the tested version. The current app does not consume or migrate those records. Use tag `v0.1.0` to reconstruct the pre-rebrand source for the IPFS measurements; the renamed experiments were not rerun during branding.
